# Custom paddle for Maxi #2 – KSV Rothe Mühle Essen

Design brief for CPS: Energy Spoon blades in club colours (red / white) on the standard black CPS carbon shaft.

`final-black-shaft/` contains the overview with production notes, both blades (back face + power face) and the shaft, as PNG previews and as SVG vector files (`svg/`).

Rebuild: `python3 build/trace_logo.py assets/rothe-muehle-logo-original.jpg assets/crest.json && node build/design.js`
