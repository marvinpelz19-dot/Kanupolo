# Paddel für Maxi #2 – KSV Rothe Mühle Essen

Designentwurf für ein CPS Energy Spoon im Rothe-Mühle-Look (rot-weiß).

- `variante-A-weisser-schaft/` – weißer Schaft, Blätter rot/weiß invertiert
- `variante-B-schwarzer-schaft/` – schwarzer Carbonschaft, Blätter rot-dominant

Je Variante: Übersicht, rechtes/linkes Blatt (Rückseite + Innenseite), Schaft – als PNG und als SVG (`svg/`).

Neu erzeugen: `python3 build/trace_logo.py assets/rothe-muehle-logo-original.jpg assets/crest.json && node build/design.js`

Hinweise für CPS: Blattkontur ist vom Produktfoto abgenommen (keine Originalschablone); der CPS-Schriftzug ist nachgezeichnet und durch das Originallogo zu ersetzen.
